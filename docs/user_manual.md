# MakanWhereSG User Manual

## Overview

MakanWhereSG helps users discover Singapore food establishments using a clean, responsive frontend prototype. The app supports search, filters, favourites, detail pages, admin actions, and analytics.

## Pages

- Home: landing page to discover featured venues.
- Browse: search and filter by area, category, cuisine, grade, and price.
- Restaurant detail: view menu and reviews, and add a review.
- Favourites: save and remove food venues using browser storage.
- Admin: add, edit, and delete mock establishment entries.
- Analytics: summary dashboard for ratings and trends.

## Using favourites

A user can click the heart icon on any card. Favourites are stored in browser localStorage and remain available during the same browser session unless cleared.

## Notes

This is the static first prototype. Future phases will replace mock data with MariaDB and MongoDB-backed APIs.
